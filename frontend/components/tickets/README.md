# Ticket Components

| File | Description |
|---|---|
| TicketsView.tsx | The page: filters, list, detail panel and the new ticket dialog |
| TicketTable.tsx | Table of tickets. Each title opens the detail panel |
| TicketDetail.tsx | One ticket with the status, priority and assignee editor |
| TicketForm.tsx | Form to create a ticket, posts to POST /tickets |
| TicketDialog.tsx | Native dialog for a form: Escape closes, focus goes in and returns |
