# UI Primitives

Shared components used across the entire app.

| File | Props | Description |
|---|---|---|
| ErrorToast.tsx | message, onDismiss | Red dismissable error notification |
| LoadingSkeleton.tsx | - | Animated grey placeholder shown while data is fetching |
| StatusBadge.tsx | status | Coloured dot + label for online/offline/warning/fault |
| ThemeToggle.tsx | - | Button that toggles dark/light class on html element and saves to localStorage |
