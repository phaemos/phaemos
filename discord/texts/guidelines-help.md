Before you post
- Search this forum and the documentation first. /docs and /faq can help.
- One question in each post. Give it a title that says what is wrong.

In your post
- What you were trying to do and what happened.
- The version you run and how you run it.
- The exact error as text in a code block. Please do not post a screenshot of text.
- What you have already tried.

Keep out of your post
- Passwords, keys, tokens and the contents of a .env file.
- Anything about a security problem. Report that privately: /security says how.

When it is solved, add the Solved tag so the next person can find the answer.
