How private help works
Some things should not be said in public: an account problem, a privacy request or a conversation about conduct.

### How to ask

- Type {command:ticket} and choose what it is about. Write a short subject and the details.
- A member of staff opens a private thread here and adds you. We aim to reply within two days. Nobody is on call.
- Only you and the staff in the thread can read it.

### Please do not

- Send a password, a key or a token. We never ask for one.
- Report a security problem here. Use /security instead.
- Ask for help with the software here. Use {channel:help} so the answer helps the next person.
