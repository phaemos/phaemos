Welcome to PHAEMOS
PHAEMOS is an open platform for predictive maintenance. Sensor nodes report what a machine is doing, a dashboard shows it and a model flags the readings that drift from normal.

This server is where we talk. GitHub is where the project is written down: the code, the issues, the releases and the long discussions. Nothing you need is only here.

The project: <https://github.com/phaemos/phaemos>
