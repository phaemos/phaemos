Welcome to the PHAEMOS community

These rules keep it useful and kind.

1. Be kind and patient. No harassment, insults or personal attacks. Our Code of Conduct applies here in full: <https://github.com/phaemos/phaemos/blob/main/CODE_OF_CONDUCT.md>
2. Stay on topic. No adverts, job offers or paid services.
3. Ask in the right place. Questions go in {channel:help} and build questions in {channel:hardware}. One post for each question.
4. Never report a security problem here, not even in a direct message. Report it privately at <https://github.com/phaemos/phaemos/security/advisories/new> or write to security@phaemos.com. We remove posts that describe a vulnerability.
5. Never post a secret: a password, an API key, a device key, a token or the contents of a .env file. If you post one by mistake, replace it straight away.
6. Share only what is yours to share. No private details about other people. No data that belongs to your employer unless you have permission.
7. Write text as text. Paste errors and logs in a code block and do not post them as a screenshot. Describe every picture you post.
8. No direct messages for support and no pings for attention. Ask in public so the answer helps the next person. We never ask for a password, a key or money in a direct message. Report anyone who does.
9. Write in English in the public channels so that everyone can follow, moderators included.
10. Bugs, feature requests and decisions live on GitHub. We may ask you to open an issue so that it is not lost.
11. Follow Discord's Terms of Service <https://discord.com/terms> and Community Guidelines <https://discord.com/guidelines>.
