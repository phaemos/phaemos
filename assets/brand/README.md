# Brand

The PHAEMOS emblem is a faceted solid seen from one corner: an ordered structure with its hidden faces
revealed, which is what the name means. The tagline is **Reveal before failure**.

## Type

Exo 2 or Space Grotesk for the name and headings, Inter or Manrope for body text.

## Using the logo

- Use the light files on light backgrounds and the dark files on dark ones. A README switches between
  them with a `<picture>` element and `prefers-color-scheme`.
- Keep clear space around the emblem of at least a quarter of its width.
- Do not recolour the emblem, stretch it, rotate it or add effects.
