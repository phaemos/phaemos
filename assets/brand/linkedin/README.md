## Tagline

## About

PHAEMOS is an open industrial IoT platform for predictive maintenance. We learn the normal behaviour of each machine and reveal the readings that break it, so a fault is found before it becomes a failure.

The platform pairs low-cost sensor nodes with a FastAPI backend, anomaly detection built on Isolation Forest models and a live dashboard that shows the health of every machine in one place.

The name comes from two Ancient Greek roots: phaen- means to reveal or bring to light. The suffix -mos means system or order. Together they mean an ordered system that reveals, which is where our tagline comes from: reveal before failure.

PHAEMOS is developed in the open on GitHub.
