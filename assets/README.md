# Assets

Images and media for PHAEMOS, kept in one place so they never scatter across component folders. This
folder is not published to a component repository.

| Folder | Contents |
| --- | --- |
| [`brand/`](brand/) | Logos, the emblem, the social preview card, colours and usage rules |

## Conventions

- Lowercase names with hyphens, starting with the subject: `phaemos-logo-dark.png`.
- Photos as JPEG at no more than 2000 px on the long edge. Logos and diagrams as SVG where possible, PNG
  otherwise.
- Every image used in the docs has alt text where it is embedded.
