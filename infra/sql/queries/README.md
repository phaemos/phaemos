# SQL Queries

Useful queries for reporting, debugging and data export. Not part of the application - run manually via psql or a DB client.

| File | Purpose |
|---|---|
| anomaly-report.sql | Summary of anomaly detections per device over time |
| device-summary.sql | Device status overview with last-seen and telemetry count |
| telemetry-export.sql | Full telemetry export for a date range - use for ML training data |
